Books

Your ebooks as knowledge for chat apps and as skills for agents. GPU Shepherd reads each book into plain text, then puts it in an Open WebUI knowledge base, where your model server's embeddings model indexes it so the chat model can quote it, or turns it into a skill: the book's methods as steps an agent like Hermes Agent follows. Only books without DRM can be read.

    Skills for agents

    A skill is a book's methods, steps and checklists written down for an agent, in the open Agent Skills format (SKILL.md). Your model server's chat model reads the whole book, a part at a time, and writes a draft: this takes a while for a long book. Check the draft, then install it in Hermes Agent.
