Knowledge Experimental

Your documents (ebooks, manuals, notes) as knowledge for chat apps and as skills for agents. GPU Shepherd reads each document into plain text, then puts it in an Open WebUI knowledge base, where your model server's embeddings model indexes it so the chat model can quote it, or turns it into a skill: the document's methods as steps an agent like Hermes Agent follows. Only documents without DRM can be read.

    Skills for agents

    A skill is a document's methods, steps and checklists written down for an agent, in the open Agent Skills format (SKILL.md). Your model server's chat model reads the whole document, a part at a time, and writes a draft: this takes a while for a long document. Check the draft, then install it in Hermes Agent.
