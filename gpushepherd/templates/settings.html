Automation (API and command line)

You don't need this to use GPU Shepherd. It is for scripts and other programs: everything on these pages can also be done with the gpu-shepherd command (on the server: sudo docker exec gpu-shepherd gpu-shepherd status) or the JSON API at /api/v1. Both use this secret token, sent as Authorization: Bearer <token>. The command on the server reads it from the data folder by itself. Whoever has it can change everything here, like the admin login.
